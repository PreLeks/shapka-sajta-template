# DevPath Header Template

Шаблон верстки шапки сайта для образовательной платформы DevPath.

## О проекте

Статичный HTML/CSS компонент — заголовок страницы с навигацией, поиском и CTA-кнопкой. Предназначен как основа для интеграции в более крупный проект.

## Функционал

- **Логотип** — брендированная ссылка (DevPath)
- **Навигация** — 4 пункта меню (Главная, Задания, Статьи, Прогресс)
- **Поиск** — интерактивная кнопка с иконкой
- **CTA-кнопка** — "Начать обучение"
- **Адаптивная вёрстка** — flexbox, контейнер макс. ширины 1700px

## Технологический стек

- **HTML5** — семантичная разметка
- **CSS3** — flexbox, медиа-запросы, переходы
- **Шрифты** — Inter (Regular, Medium, Bold) в формате WOFF2

## Структура проекта

```
├── index.html          # Разметка шапки
├── css/
│   └── style.css       # Стили компонента
├── fonts/              # Кастомные шрифты
├── img/                # Медиа-ресурсы
└── verstaem.json       # Метаданные задания
```

## Быстрый старт

1. Откройте `index.html` в браузере
2. Или используйте live-server:
   ```bash
   npx live-server
   ```

Учебный проект для платформы [verstaem.online](https://verstaem.online/tasks/shapka-sajta). Демонстрирует практики современной верстки и структурирования CSS.
